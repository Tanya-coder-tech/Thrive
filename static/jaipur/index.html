AI-900 Core Concept: Document Intelligence vs Raw Optical Character Recognition (OCR)

Standard OCR (such as Azure Computer Vision Read API) outputs unformatted text streams with bounding boxes. In contrast, Azure AI Document Intelligence applies semantic machine learning models that understand receipt taxonomies: distinguishing item quantities from prices, detecting column alignments, and tying line items directly to calculated totals.

Mathematical Formula: Proportional Tax Distribution

For each member $i$, their proportional share of shared bill-level tax is calculated using integer paise precision:

TaxShare_i = floor((ItemSubtotal_i * BillTax) / BillItemSubtotal) + RemainderPaise_i
Aman Tax = floor((25000 * 4000) / 80000) = 1250 paise = ₹12.50
Simran Tax = floor((25000 * 4000) / 80000) = 1250 paise = ₹12.50
Karan Tax = floor((30000 * 4000) / 80000) = 1500 paise = ₹15.00
Total Tax Sum = 1250 + 1250 + 1500 = 4000 paise (₹40.00) ✓ Zero Drift Guarantee

Describe Artificial Intelligence Workloads

Fundamental Principles of ML on Azure

Azure Cognitive Services integration patterns, REST API endpoints, and confidence scoring.

AI-900 Exam Tip: Form Recognizer vs Azure AI Document Intelligence

In Microsoft Azure certifications, Azure Form Recognizer was rebranded to Azure AI Document Intelligence. Key concepts tested on AI-900 include: (1) Prebuilt Models (Receipts, Invoices, Business Cards, ID Documents), (2) Layout Analysis (detecting tables, selection marks, and text lines), (3) Custom Extraction Models (training custom template vs neural models with labeled sample documents).

Software Engineering Caution: The Floating-Point Accounting Trap

In JavaScript and Python, standard IEEE 754 64-bit floating point arithmetic produces fractional rounding errors (e.g. 0.1 + 0.2 = 0.30000000000000004). In shared group portals, accumulated rounding errors cause ledger imbalance. Thrive solves this by strictly parsing and storing all currency as integer paise (₹1 = 100 paise), guaranteeing exact zero-sum balance conservation.
